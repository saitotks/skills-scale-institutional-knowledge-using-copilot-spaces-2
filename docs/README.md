# OctoAcme Project Management Docs

This README is the starting point for OctoAcme's project management guidance. The documents below describe the project lifecycle, the practices and artifacts used at each stage, and the responsibilities of the people involved.

## Project management at a glance

OctoAcme moves work from initiation and stakeholder alignment through planning, iterative execution, and controlled release, then uses retrospectives to turn lessons into continuous improvements. Teams clarify outcomes and success measures up front, prioritize work into manageable increments, track progress and quality throughout delivery, and identify, mitigate, and communicate risks and dependencies. Project Managers coordinate plans, delivery, risks, and communication; Product Managers own product outcomes and prioritization. Developers, QA, and stakeholders contribute across the lifecycle.
